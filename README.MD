
# NECO.AI v2

Türkçe sohbet ve kodlama asistanı.

## Model
- Temel model: Qwen/Qwen3-0.6B
- Eğitim: NECO.AI v2 LoRA adaptörü
- Arayüz: Gradio

## Özellikler
- Türkçe sohbet
- Kod yazma
- Kod hatalarını açıklama

## Çalıştırma

Gerekli paketleri yükle:

```bash
pip install -r requirements.txt
```

Uygulamayı başlat:

```bash
python app.py
```
